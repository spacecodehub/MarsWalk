# MarsWalk GIS data and validation

This directory contains the global MOLA map renderer and local Mars raster
sources. Regional SIM 3464 data are kept under `Datasetmars/data/raw/geology/`.
The machine-generated inventory and validation results are in
[`documentation/`](documentation/).

## Rebuild the inventory and validation reports

The scripts use the GDAL/OGR Python bindings bundled with QGIS and the local
Git executable. On Windows, run them from the repository root with the QGIS
Python launcher:

```powershell
& "C:\Program Files\QGIS <version>\bin\python-qgis-ltr.bat" GIS\scripts\generate_inventory.py
& "C:\Program Files\QGIS <version>\bin\python-qgis-ltr.bat" GIS\scripts\validate_gis.py
```

If Git is not on `PATH` and is not installed with GitHub Desktop, set
`MARSWALK_GIT_EXECUTABLE` to the full path of `git.exe`. The scripts read source
datasets only; they write CSV reports in `GIS\documentation\`. The inventory
includes byte sizes and SHA-256 checksums for individual files. A FileGDB is
reported as a directory dataset and does not have a single-file checksum.

Run the geotransform unit tests with the standard library:

```powershell
python -m unittest discover -s GIS\scripts -p "test_*.py"
```

## Scope and readiness

- The included React map uses the global MOLA topography image for context; it
  is not a regional route or terrain-safety product.
- The source bundle contains the SIM 3464 FileGDB and regional raster layers,
  MOLA topography/areoid products, and the tracked HiRISE IRB orthophoto.
- HiRISE DTM and RED orthophoto files in `GIS\raw_data\` are local-only and
  intentionally excluded from this contribution. See the P2 handoff for
  source URLs and distribution constraints.
- No regional slope, aspect, roughness, reprojection, or resampling products
  are generated by these scripts. The HRSC hillshade is a source-package
  visualization product, not an output of the validation workflow.
- There is no QGIS project. The validation script checks GDAL readability,
  FileGDB layer geometries, and approximate footprint overlap; overlap does
  not establish raster registration or positional accuracy.

See [`documentation/P2_HANDOFF.md`](documentation/P2_HANDOFF.md) for CRS and
units, provenance, limitations, and downstream integration guidance.
